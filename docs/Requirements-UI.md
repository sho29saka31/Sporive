# Requirements: UI（Sporive）

[Requirements](Requirements.md) の一部。画面構成・UI要件(要件定義書 §9)。

## 9-1. header（固定・常時表示）
- お知らせ（通知履歴・お知らせタブ切替、[Requirements Notifications](Requirements-Notifications.md) 参照）へのショートカット（ベルアイコンなど）
- アカウント設定へのショートカット

## 9-2. footer（固定・常時表示・下部タブ）
スクロール時も含め、常にheaderとfooterの両方を画面上に固定表示する（headerと同様の扱い）。

4タブ構成：

| タブ | 役割 |
|---|---|
| ホーム（メイン） | 今日のトレーニング実行画面、AI提案の確認・実行 |
| スケジュール（サブ） | 週間トレーニング予定 |
| 進捗（サブ） | セット数・重量・回数のログ、連続達成記録 |
| すべて | 負債管理など、上記に含まれないその他機能への一覧アクセス |

## 9-3. レスポンシブ対応
- 利用者側：スマホ専用。それ以外のデバイスでは「スマホで開いてください」という誘導画面を表示
- 管理者側：PC・タブレット専用
