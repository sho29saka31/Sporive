# Requirements: Overview（Sporive）

[Requirements](Requirements.md) の一部。プロジェクト概要・対象ユーザー(要件定義書 §1, §2)。

## 1. プロジェクト概要

**Sporive** は、理想の体づくりに向けて、AIによるパーソナライズされたトレーニング計画を提案するPWA（Progressive Web App）。
若者からシニアまで幅広い層を対象とし、シニア層には筋力維持・向上を主眼とした提案を行う。
継続的なモチベーション維持のため、進捗の可視化・通知機能・連続達成記録・負債管理（未達成分のリカバリー）を実装する。

- **デモ版**：2026年7月末目標
- **試験運用**：2026年8月〜
- **コスト方針**：すべて無料プラン内で運用
- **ドメイン**：`sporive.saka2931.jp`(当初はVercelの無料共有サブドメインで運用していたが、saka2931.jpドメイン取得後に移行済み)

## 2. 対象ユーザー

- 若者〜シニアまで幅広い年齢層
- シニア層には筋力維持・向上を重視した低強度中心の提案を行う
- 利用者側の画面は**スマホ専用**。スマホ以外でアクセスした場合はスマホで開くよう促す画面を表示
- 管理者画面は**PC・タブレット専用**
